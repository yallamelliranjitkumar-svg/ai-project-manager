# The AI Project Manager

**I don't code. I build with AI.**

An interactive 3D website where a glowing "project" sphere evolves through six
chapters (Define, Plan, Delegate, Monitor, Decide, Deliver) as you scroll,
showing how AI agents and a human project manager deliver a project together.

It was designed and built entirely by directing [Claude Code](https://claude.com/claude-code)
as a product team: architect, designer, developer and QA. I made the decisions.

- Creative brief: [BRIEF.md](BRIEF.md)
- Design system: [docs/DESIGN.md](docs/DESIGN.md)
- Build diary: [docs/BUILD-LOG.md](docs/BUILD-LOG.md)

## Built with

React · Vite · TypeScript · Three.js · React Three Fiber · GSAP · Motion. The site is static (no backend) and hosted on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.
